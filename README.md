# LeadRescue

LeadRescue AI launch assets and implementation blueprint.

## What's included

- `docs/leadrescue-30-day-launch-kit.md`: 30-day offer, delivery, and sales playbook.
- `src/pages/LeadRescuePage.tsx`: Conversion-focused `/leadrescue-ai` landing page.
- Reusable React components for pricing cards, workflow steps, industries, FAQ items, audit form, and metric cards.

## Run locally

```bash
npm install
npm run dev
```

Then open: `http://localhost:5173/leadrescue-ai`.

## Build

```bash
npm run build
```
